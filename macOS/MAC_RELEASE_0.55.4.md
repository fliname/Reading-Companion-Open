# macOS 0.55.4（Build 112）

## 阅读与划线

- EPUB / AZW3 / MOBI：拖选时即时显示淡蓝色；拖到页面右侧边缘停留约半秒后自动翻页，继续拖选。选区在翻页及打开操作浮窗后保留淡蓝色，点击划线颜色后才改成对应颜色。支持跨章节的一次选区。
- 电子书人物管理保存时保持阅读位置；三栏使用固定位置的容器，管理面板和 AI 面板切换不再重新分配栏宽。
- 锁定时保持阅读区和左右栏的宽度，禁用分隔条拖动和改变布局的按钮。窗口缩小时保持已锁定宽度，多出的区域会被裁切；解锁后随窗口恢复自适应。
- 右下角书名使用原始文件名（不含扩展名）。
- 批量人物输入支持 `人物名字/别名/另一个别名：信息`，支持全角斜杠；别名可省略，空别名和重复别名自动忽略。
- 书架文件夹右侧增加删除按钮；只删除分组，书籍和阅读记录保留。

## PDF

- 顶栏增加单页 / 双页切换；双页按两页翻页，底栏显示当前范围。
- 锁定同时记录当前可见区域在页面中的位置和比例。翻到下一页时保持相应截取范围，包括上、下裁去的空白。
- 划线显示高度收窄，保留原始选区坐标用于文本提取；同一行中相邻 OCR 片段合并后使用连续矩形填色，减少中间断色和上下行重叠。

## 阅读位置、概要和目录

- 先恢复保存的阅读状态，再建立阅读视图；初始化回调不再把阅读位置覆盖为第一页。
- 电子书保存章节与正文偏移，同时保存当前页码、字号和布局参数。相同布局恢复原页，布局改变时恢复对应原文。
- 虚构类已生成概要可点击页码或正文跳转。PDF 跳到该范围起始页；电子书按保存的正文位置跳转。
- 电子书重排后，目录显示页码、已生成概要的页码范围和已输入的待生成范围会重新换算。概要生成读取当前排版对应的正文，并同时保存范围的正文锚点。
- 旧版概要只有页码，没有正文锚点；首次打开时按当前排版建立锚点。旧概要生成时的历史字号和栏宽无法从旧数据中还原，因此可能需要核对一次范围。
