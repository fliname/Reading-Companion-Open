# 隐私说明

- PDF/EPUB/AZW3/MOBI、OCR、章节化 Markdown、索引、检索、书签、划线、批注、人物与 Obsidian 写入默认在本机处理。
- 无 DRM 的 AZW3/MOBI 由安装包内的 libmobi 0.12 独立进程离线转换，不上传书籍。
- 仅当用户主动发送 AI 请求时，问题和检索出的相关原文片段会发送到用户自行配置的 API 服务商；默认不会上传整本书。
- “联系全书”会扩大本地检索范围，但仍只发送命中预算的片段。
- API Key 在 Windows 上使用系统 DPAPI 支持的 `safeStorage` 加密保存；请勿在截图、日志或公开仓库中提交真实密钥。
- 项目缓存位于 `%APPDATA%\\reading-companion-windows\\ReadingCompanion\\Documents`，可从书架按书删除。
- 不包含遥测、广告 SDK 或 Claude 网页端自动化。
