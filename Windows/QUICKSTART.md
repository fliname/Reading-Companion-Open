# 快速上手

1. 安装 Reading Companion Open；Portable 版请完整解压后运行 `Reading Companion Open.exe`。
2. 安装 Obsidian，创建或打开 Vault。
3. 打开设置，输入 API Key；中转站再填 Base URL。验证成功后选择模型。
4. 点击“打开”导入 PDF、EPUB、AZW3 或 MOBI，选择非虚构类或虚构类，等待底栏显示“全文索引已就绪”。
5. 打开左侧“目录”，点击“自动识别”；轻量引擎会先用原生目录和已有文本，必要时才 OCR 前部页面。若结果不可靠，使用“手动添加”解析并调整标题、页码、层级和顺序。
6. 抽查第一条、正文第一章和末条目录的跳转。
7. 依次点击“创建笔记本”“添加目录到笔记”“打开笔记本”。
8. 拖选原文后选择划线、批注、复制或提问；结果可从左侧列表或 AI 对话栏加入笔记。虚构类还可在“概要”按页码生成情节摘要，在“人物”建立人物与别名索引。

非虚构类节省费用时优先使用“节省”与“解释一下”；需要本章论证链时用“联系上下文”。虚构类默认短回答；两类都只有在确需跨章节比较时才勾选“联系全书”。
