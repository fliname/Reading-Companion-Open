# 故障排查

## Windows 阻止安装

当前社区安装包可能没有商业代码签名。请核对文件来源和校验值后，在 Windows 安全提示中选择“仍要运行”。公开发布前建议使用受信任的 Windows 代码签名证书签署安装包。

## API 连接失败

- 确认 Key 有余额、模型权限且没有 IP 白名单限制。
- 官方 Key 通常不填 Base URL；独立中转站填写其根 URL。
- 若平台只提供网页调用、私有签名或非标准接口，无法保证兼容。
- 连接成功但没有模型时，通常是 `/models` 权限或中转站模型映射问题。

## OCR 很慢或不准确

首次扫描件 OCR 会占用 CPU；完成后会持久化缓存。简体、繁体和英文语言包已随安装程序提供。复杂竖排、低清晰度或装饰字体仍可能需要手动校正目录。

## AZW3/MOBI 无法打开

- 0.44.0 安装包应包含 `resources\BookConverter\mobitool.exe` 和 LGPL 许可证；若提示“缺少解码组件”，请重新安装完整版本。
- 只支持无 DRM 的 MOBI/KF8/AZW3。带 DRM 的 Kindle 文件会被明确拒绝。
- 文件被替换后会按源文件指纹自动重建缓存；也可在书架右键该书并删除缓存后重试。

## 目录页码不准

先检查 PDF 是否包含封面、罗马页码或前言后重新从 1 计页。自动识别会用标题锚点校准，但印刷页码异常时请在“手动添加”中修改。无页码的“上篇/下篇/第一部分”等标题会继承下一条页码。

## 语音输入不可用

Windows 语音依赖系统已安装的语音识别语言。请在“设置 > 时间和语言 > 语音”安装中文或所需语言，并允许麦克风。停顿不会清空已识别内容；再次点击麦克风结束并保留文本。

## Obsidian 无法打开笔记

先在 Obsidian 中打开目标文件夹作为 Vault。随后在 Reading Companion 设置中选择相同 Vault 根目录。默认路径为“文档\\Obsidian”。

## 完全重置一本书

打开“书架”，右键对应书籍并选择“删除缓存”，或在批量管理中删除。该操作删除排版/OCR、Markdown、目录、概要、人物、书签、划线、批注和对话缓存，但保留原始书籍与 Obsidian 笔记。
