# Reading Companion Open Windows 0.44.0

本版本以 Windows 0.43.23 为基线，迁移 macOS Open 0.43.12 至 0.55.3 的公开阅读功能。

## 新增与改进

- EPUB、无 DRM 的 AZW3/MOBI 流式阅读、稳定位置、封面和缓存；libmobi 以独立 LGPL 进程随包提供。
- 书架类型筛选、强制新旧书分类、自建文件夹、多文件夹成员关系、批量整理、右键菜单和完整缓存清理。
- 虚构类短回答、实际页码范围概要、人物/别名管理、独立配色、全文高亮和精确出现位置导航。
- PDF 与流式书籍的全文搜索均改为点击结果后精确定位，同页重复命中互不混淆。
- 无导航电子书可从正文标题生成目录，重排书籍的自动/手动目录不再误走 PDF OCR 路径。

## 轻量目录与体积优化

- 不包含 macOS 的 EnhancedTOC、Python、Torch 或任何联网目录模型。
- 新的轻量 JavaScript 自动目录引擎优先读取原生目录、复用已有文本索引，仅在必要时对文档前部最多 48 页调用内置 OCR。
- PDF.js 与 Markdown 解析器改为仅构建时依赖，避免在应用中重复打包。
- Tesseract 只保留 LSTM 运行核心与简体中文/英文模型；Electron 只保留简中/英文语言包，并排除错误平台 Canvas 二进制。
- Windows 解包目录由优化前约 496 MB 降至约 353 MB，减少约 143 MB（约 29%）。

## 验证

- 55 项自动测试全部通过。
- 已验证 Windows 主程序和 `mobitool.exe` 均为 x86-64 PE，可执行包内包含 LGPL 许可证。
- 仍需在 Windows 10/11 x64 真机完成安装/卸载、DPAPI、语音和代表性 PDF/EPUB/MOBI 的端到端验收。

Claude 网页端、网页对话同步和网页编辑器自动写入不属于公开版迁移范围。
