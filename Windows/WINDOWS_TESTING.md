# Windows 验证说明

自动测试覆盖：原有 PDF/OCR/目录/检索/Obsidian 服务，以及 EPUB 稳定位置与导航、多文件夹和分类迁移、电子书缓存、人物批量格式/别名/配色、虚构类提示词、精确搜索入口、libmobi 打包声明和 0.44.1 版本契约。

发布前应在 Windows 10/11 x64 真机完成：

1. 安装、卸载、桌面和开始菜单快捷方式。
2. 文本 PDF 与扫描 PDF 的打开、OCR、重启缓存复用；扫描页必须能拖选文字并完成划线、批注、复制和提问。
3. EPUB 3/EPUB 2 目录、内嵌封面、动态分页、单双页、字号重排、滚轮翻页、搜索、划线、批注和缓存复用。
4. 用无 DRM 的 MOBI6、KF8/AZW3 各一本验证离线转换；带 DRM 文件应显示明确错误。安装目录必须包含 `BookConverter\mobitool.exe` 与许可证。
5. 目录跳转、手动编辑；搜索提交时页码不动，点击同页多个重复命中时分别精确定位；划线/批注/跨页合并。
6. 书架强制类型选择、旧书一次性未分类、类型筛选、多文件夹加入/移出、右键整理、内嵌/生成封面和完整缓存删除。
7. 虚构类隐藏阅读深度与快捷问题，短回答无碰撞；实际页码范围概要可保存多条；PDF/EPUB 人物别名高亮、首次强调、11 条窗口和上/下一次跳转。
8. Windows 中文语音输入，停顿累积和主动结束保留。
9. 至少一个官方 API 与一个 OpenAI-compatible 中转站；验证 AI 取消、流式显示、上轮用量、联系全书与上下文切换。
10. 在 Obsidian 先注册 Vault，再验证创建目录、打开笔记、各类内容写入正确章节并保持颜色；包含中文、空格和 `+` 的 Vault/文件名都应可打开。
11. 书架第一本复用当前窗口、第二本新窗口；在导入、OCR、语音或 AI 工作中以及完成后分别关闭窗口，均不应出现主进程 JavaScript 错误。

macOS 上可以交叉生成 Windows 应用目录或 Portable ZIP 并检查 PE/asar 结构，但不能代替 Windows 真机的语音、DPAPI、安装器和系统集成验证。若本机的 x86_64 NSIS 在 Apple Silicon 上无法运行，可先执行 `pnpm run dist:zip`；正式安装器由 Windows CI 执行 `pnpm run dist:win` 生成。
