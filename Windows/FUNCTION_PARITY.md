# 功能迁移清单

Windows 公开版 0.44.0 基于 Windows 0.43.23，并完成 macOS Open 0.43.12 至 0.55.3 的跨平台迁移。平台替换仍为：Vision → Tesseract、Speech → Windows System.Speech、Keychain → DPAPI、DMG → NSIS；Claude 网页自动化继续不迁移。

## 0.44.0 对照核查

- 删除 Mac 增强目录组件的迁移路径；自动目录改为独立轻量 JavaScript 引擎，优先读取原生目录、复用全文索引，并只在必要时对前部最多 48 页做本地 OCR。发布包明确排除 EnhancedTOC、Python/Torch 和错误平台的 Canvas 二进制。
- 新增 EPUB、AZW3、MOBI 的选择与拖放；EPUB 3 nav / EPUB 2 NCX、内嵌图片和封面进入统一流式阅读器。
- 流式正文支持动态分页、单/双页、150ms 翻页、字号/栏宽重排、文字级划线/批注、书签、检索、AI、Obsidian 与源指纹缓存。
- 打包 libmobi 0.12 `mobitool.exe` 和 LGPL 全文，以独立进程离线处理无 DRM MOBI6/KF8/AZW3；CI 从随源码提供的上游源码构建并烟测。
- 书架新增全部/非虚构/虚构筛选、自建文件夹、多文件夹成员关系、批量加入/移出与分类、单书右键菜单、文件夹删除、嵌入/生成封面和完整缓存清理。
- 新书与升级旧书强制选择类型；分类同步进入项目状态、AI 模式与回答缓存键。虚构类隐藏阅读深度和快捷问题，回答 120–300 汉字且无 `ljg-read`/碰撞。
- 虚构类概要栏原位覆盖目录栏，按当前实际阅读页提取起止范围；多条结果置顶、持久化并可删除。
- PDF 与流式书籍共享人物索引/管理：批量“人物：信息”、单个增删改、别名、唯一颜色、默认全文高亮、首次强调、以当前页为中心的最多 11 条出现和精确上/下一次跳转。
- 全文搜索提交不移动当前页；结果逐次记录命中，点击后对 PDF 与流式正文执行精确文字定位，同页重复词不再只跳到页面。
- 新增 EPUB、书架迁移/多文件夹/缓存、人物、虚构提示词、精确搜索和打包契约测试；旧版 PDF/OCR/目录/笔记测试继续保留。

## 0.43.23 对照核查

- 手动目录先锁定实际检测到的连续目录物理页，不再根据粘贴标题猜测目录范围；目录后的装饰章页会截断范围，正文脚注和独立页码不会被吞入目录。
- 保留目录中的印刷页码，并单独显示可修正的实际 PDF 跳转页；`CHAPTER 01` 等英文序号保持原顺序。
- 强制 OCR 写回时同时保留 PDF 原文本层作为校准证据，解决白字黑底、复杂底图章页被 Tesseract 读成乱码后覆盖可用标题的问题。
- 短标题只接受独立标题行作为锚点，避免“自拍”“安静”等正文词误抢章节位置；未识别的复杂章页由前后可靠锚点插值或外推。
- PDF 页标签新增中文和前缀格式支持；数字标签仍作为扫描书正文页码的权威映射。
- 已以《非物》《论摄影》《故事》三本实际 PDF 验证：分别通过 15、8、19 条手动目录跳转校准；《非物》另完成 91 页正式 OCR 校准窗口复跑。

## 0.43.17 对照核查

- Ctrl 可在同页或隔页持续追加选区；第一段即进入暂存，所有片段的淡蓝预览在翻页和页面重绘后继续保留，确认后以“•”和换行保存为同一条划线。
- 划线与批注搜索会同时在 PDF 原文标出查询词和匹配记录位置；全文搜索也在页面上绘制高层级黄色命中层。两类搜索仅在对应侧栏激活时显示，互不残留。
- 全文搜索执行后右侧按钮切换为“取消”，可一键清空查询、结果列表和页面命中高亮。
- 扫描页搜索改为按 OCR 逐词坐标绘制命中框，不再依赖不稳定的透明文字 Range；已用指定扫描 PDF 验证页面黄色高亮与一键取消。
- 目录建立工具默认折叠；点击目录标签或标题后才显示“自动识别、手动添加、恢复自带目录”。打开文档会优先读取原生目录，无原生目录时状态和空列表均明确显示“PDF 无自带目录”。
- 手动添加目录不再要求“目录页 X 至 X”。条目显示与粘贴内容一致的印刷页码；内部跳转页由软件自动定位目录页、排除目录页重复标题后，再依据正文标题锚点校准。
- 页码校准迁移 Mac 版的分页分段、正文标题单调锚点、多条目偏移共识和非默认 PDF 页标签逻辑；手动目录还会利用粘贴条目识别只有两条或缺少“目录”标题的目录页，避免再次把目录页本身选为正文锚点。
- Windows 扫描 PDF 渲染增加单页画布与 OCR 临时画布预算，关闭细节画布的延迟替换，显式释放 OCR backing store；窗口恢复、画布上下文丢失或渲染失败时自动重绘可见页，避免长时间阅读后出现黑屏。
- 扫描页选区改为自绘：按纵向距离优先锁定行并按视觉顺序排列，跨到下一行时不会被更长的上一行吸回。
- OCR 缓存新增逐词坐标；选区首尾按词与字符收口，确认划线时不再二次读取浏览器原生选区，因此不会把行末空白写入划线。旧缓存自动升级重建。
- 三色划线透明度降低，保留原文字形对比度；批注继续使用绿色下划线。
- 对齐 Mac 版，在“划线与批注”栏加入搜索框：同时搜索划线原文与批注内容、标黄命中词，并可与颜色/批注筛选叠加。
- 中文扫描件默认使用简体中文与英文 OCR，避免简体原文因同时加载繁体模型而混入繁体字；OCR 缓存版本同步升级并自动重建。
- 目录为空时不再显示“可自动识别或手动添加”提示；笔记操作按钮简化为“添加目录”。

## 0.43.11 对照核查

- 扫描型 PDF 增加逐词 TSV 坐标回退：OCR 缺少标准文本块时仍可重建可选文字行；同时增加基于坐标的拖拽选区回退，确保纯图片页能划线。
- 扫描页改为逐页 OCR、逐页启用选区，不必等待整本书识别完成；旧 OCR 缓存会自动升级重建。
- 已用不含任何文本层的图片型 PDF 完成端到端验证：拖拽后显示划线浮窗、确认后原图保留颜色划线、点击空白处可取消未确认浮窗。
- 可搜索型 PDF 以原生文本选区为准，不再对正常选区二次 OCR；因此不会把简体改成繁体，也不会因 OCR 裁剪扩边多收前后文字。只有出现乱码方框或私用区字符时才启动纠错，并要求纠错前后字符数一致。
- 左右侧栏统一增加水平与顶部内边距，目录、记录、搜索、AI 标题、消息区、快捷按钮和输入区不再贴边。
- AI 发送键改为蓝色；快捷问题、联系全书、展开与语音控件缩小；删除和加入笔记取消灰底，并在发送键下方靠右并排。

## 0.43.10 对照核查

- PDF 选区矩形改为按文本范围、页面交叠和多点命中联合定位，兼容更多文本层结构、跨页选区和旋转页面；未确认划线时点击外部会立即取消选区与浮窗。
- 目录概要改为 Mac 同款右上角总开关，开启后在目录条目前显示展开键；书签、搜索、搜索结果、AI 对话和笔记按钮统一为 Mac 浅色无边框风格。
- Windows 原生“文件 / 编辑 / 视图 / 窗口”菜单及全部子项改为中文。

- 阅读区：单页连续阅读、适宽/整页、缩放、旋转、锁定、底栏翻页、触控屏双指缩放均已接线；导航栏与 AI 栏可分别拖动边界调整宽度并持久化。
- 左侧导航：目录、缩略图、书签、划线与批注、搜索五栏齐全；目录和划线条目采用 Mac 风格的无外框列表，划线以颜色圆点区分。
- 搜索：结果文字与 PDF 原文同时使用黄色命中标记；清空搜索会同步清除原文标记。
- AI：设置使用标准齿轮；展开问题和 Windows 语音输入均有实际处理；底部全选、删除、加入笔记保持同一横向基线。
- 设置：API 与 Obsidian 分页；官方 Key 可自动识别服务商并验证，自定义 API 支持 Key + Base URL 以及 `newapi_channel_conn` JSON 自动填充。
- 笔记：上栏笔记按钮打开统一笔记中心，包含 Vault、创建笔记本、添加目录、打开笔记、划线/批注与对话加入笔记等入口。
- Obsidian：读取 Windows 的 Obsidian Vault 注册表，只接受已注册 Vault，并通过 Vault 名称与相对 Markdown 路径打开笔记，避免 `obsidian://open?path=C:\\...` 导致的 `Vault not found`。
- 扫描件选择：OCR 索引同时持久化每行文字坐标，扫描页渲染可选择文字层，可使用与文本型 PDF 相同的划线、批注、复制和提问流程；旧索引会自动重建一次。
- 生命周期：窗口关闭时先保存 WebContents 标识，退出清理不会再访问已销毁的 BrowserWindow/WebContents。

硬件验收项：Windows System.Speech 依赖系统已安装的中文语音识别组件；触控缩放依赖设备向 Electron 提供标准双指 Pointer Events。这两项需要在目标 Windows 触控设备上做最终验收。

有意不迁移：Claude 网页端、网页对话同步、网页编辑器自动写入及其备用导入按钮。Anthropic Claude **API** 仍作为普通 API 服务兼容，不属于网页端功能。

平台适配：Mac 的 Vision OCR 改为随安装包提供的 Tesseract OCR；Mac Speech 改为 Windows System.Speech；Keychain 改为 Windows DPAPI；Launchpad/DMG 改为开始菜单、桌面快捷方式和 NSIS 安装程序。
