# Windows 0.44.3 · 基于 0.44.1

本版同步修复两个电子书阅读遗留问题：

- EPUB / AZW3 / MOBI 图片缓存升级后自动重建，并按当前阅读页正文高度约束大图。
- 页面偏下位置选中文字或点击已有划线时，操作浮窗固定显示在选区下方。

同时保留 0.44.2 中从 macOS 版同步的 Obsidian 笔记属性与蓝色批注、全局方向键翻页、批量管理文件夹删除、已有划线修改和默认开启的 `ljg-read` 开关。
